Private by design

Current uses Supabase Auth, PostgreSQL, Realtime, Storage, and Edge Functions. Messages are designed to be encrypted on the client before being stored.

Open source

Current is built to be transparent. The goal is software users can inspect, modify, and trust.

Supabase stack

Authentication: Supabase Phone OTP

Database: PostgreSQL with RLS

Realtime: Messages, typing, presence

Storage: Encrypted media attachments
